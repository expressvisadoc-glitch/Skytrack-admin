# Using the phone app or the web portal

## What this feature does

You can use SkyTrack two ways, with the same account and the same data:

- **The Android app** — for daily check in and check out.
- **The web portal** in any browser — the same features on a computer.

Whatever you do in one appears in the other. There is no separate login.

## Who can use it

Employees. Administrators use the web portal only; there is no admin app.

## Prerequisites

The same employee ID and password for both.

## Which to use

| Task | Best place | Why |
| :--- | :--- | :--- |
| Checking in and out | **Phone app** | Your phone knows where it is; a laptop usually does not |
| Taking a break | Either | No location check |
| Applying for leave | Either | |
| Reading your monthly attendance | Either | Easier on a bigger screen |
| Downloading a payslip or timesheet | Either | |

## Expected outcome

The same information, whichever you open.

## Common mistakes

- **Trying to check in from a laptop.** A laptop has no GPS and estimates its position from Wi-Fi, often
  hundreds of metres out — so the check-in may be refused for poor accuracy. Use your phone.
- **Thinking you must check out on the same device you checked in on.** You do not.

## Troubleshooting

If the app shows something different from the browser, pull down to refresh, or sign out and back in.
