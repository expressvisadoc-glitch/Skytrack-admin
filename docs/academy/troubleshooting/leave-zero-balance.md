# A leave type is greyed out

## Symptom

When applying for leave, **Casual** or **Sick** cannot be selected.

## Cause

Your balance for that type is **zero**. SkyTrack disables it so you do not apply for paid leave you have not
got.

## Fix — you can still take the time

Apply as **Loss of Pay (LOP)** instead. LOP never has a balance, so it is always available. The time off is
granted the same way; the day is simply unpaid.

1. Open **Leave Requests** and start a new request.
2. Choose **Loss of Pay**.
3. Enter the dates and reason, and submit.

## Expected outcome

The request goes for approval. If approved, the days are unpaid — about one day's pay per day.

## If you believe you do have balance

Balances are `allocated + adjustments − used`. Check your approved requests: approved leave uses balance at
the moment of approval. If it still looks wrong, ask an administrator — they can adjust it, and the change
is recorded.

## Common mistakes

- **Assuming a greyed-out type blocks the leave entirely.** It does not — only the *paid* version.
- **Asking for a balance adjustment after a request is approved.** The paid/unpaid split is fixed at
  approval; adjusting afterwards does not convert it.
