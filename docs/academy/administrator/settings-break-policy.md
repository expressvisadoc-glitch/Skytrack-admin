# Setting the allowed break length

## What this feature does

Sets the break length after which an employee is reminded. It appears in the app as, for example,
*Break (1h Max)*.

## Who can use it

Administrators and super administrators.

## Step-by-step instructions

1. Open **Payroll Settings**.
2. Set **Allowed break (minutes)**.
3. Save and confirm.

## Expected outcome

The figure shows in the app, and an employee whose break runs longer may be notified.

## It does not change pay

This is a **reminder only**. Exceeding it costs nothing automatically. SkyTrack reduces pay for exactly
three things: unapproved absence, unpaid leave, and lateness.

A long break does reduce recorded **working hours**, because hours exclude break time.

## Common mistakes

- **Expecting a long break to be deducted.** It is not. Enforcement is a management conversation.
- **Setting it to the total daily allowance when staff take several breaks.** It is about break time
  overall, so set it to what you consider the total reasonable break.
