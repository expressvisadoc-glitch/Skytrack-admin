# Resetting an employee's password

## What this feature does

Sets a new password for an employee who cannot sign in.

## Who can use it

**Super administrators only.** An ordinary administrator cannot reset passwords.

## Prerequisites

Confirm who you are talking to. A password reset hands over access to somebody's attendance and salary.

## Step-by-step instructions

1. Open the employee's record, or **Admin Management**.
2. Choose the password reset action.
3. Set a new password meeting the rules: 8+ characters with upper and lower case, a number and a symbol.
4. Give it to the employee **directly**, not in a group chat.
5. Ask them to change it once they are in.

## Expected outcome

The employee can sign in with the new password. **Every existing session on their account ends**, so they
will be signed out on their phone too.

## Nobody can read an existing password

Passwords are stored so that they cannot be read back — not by you, not by anyone. The only option is to set
a new one.

## Common mistakes

- **Sending the new password to a staff group.** Send it directly.
- **Not asking them to change it.** They should set their own.
- **Resetting on a phoned request without verifying identity.**

## Troubleshooting

If they still cannot sign in, check the record is **active** and that they are using the right employee ID.
