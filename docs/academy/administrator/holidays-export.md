# Exporting the holiday calendar

## What this feature does

Downloads the holiday calendar as a CSV file you can open in a spreadsheet or share.

## Who can use it

Administrators and super administrators.

## Step-by-step instructions

1. Open **Public Holidays**.
2. Choose the CSV export.
3. The file downloads to your computer.

## Expected outcome

A spreadsheet of holiday dates, names and types.

## Common mistakes

- **Treating the export as the source of truth.** The calendar in SkyTrack is. Editing the CSV changes
  nothing.
- **Sharing it as next year's calendar** when it only holds what has been entered so far.
