# Seeing who is on a break

## What this feature does

Shows which employees are on a break right now, with a live timer.

## Who can use it

Administrators and super administrators.

## Step-by-step instructions

1. Open **Dashboard** for the live count, or **Attendance** and use the on-break tab for the list.
2. Each row shows how long that break has been running.

## What you can and cannot see

| You can see | You cannot see |
| :--- | :--- |
| Who is on a break now | A list of each separate break |
| How long the current break has run | When each earlier break started or ended |
| The total break time for the day | Where someone is during a break |

SkyTrack stores the **total** break time per day, not individual break records. If per-break history matters
to your organisation, that is a product change, not a setting.

## Expected outcome

You know who is away from work at this moment.

## Common mistakes

- **Expecting a break to be location-checked.** Breaks are deliberately not geofenced — only check-in and
  check-out are.
- **Expecting a long break to dock pay automatically.** It does not. The allowed break is a reminder only.
