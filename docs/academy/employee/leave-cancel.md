# Cancelling a pending request

## What this feature does

Withdraws a leave request you submitted, so it will not be decided.

## Who can use it

Employees, for their own requests.

## Prerequisites

**The request must still be Pending.** Once it has been approved or rejected you cannot cancel it yourself.

## Step-by-step instructions

1. Open **Leave Requests**.
2. Find the request in your history. It must show **Pending**.
3. Select it and choose to cancel.

## Expected outcome

The request moves to **Cancelled**. No balance is used and no deduction is made. You can apply again for the
same dates.

## Common mistakes

- **Trying to cancel an approved request.** You cannot. Ask an administrator — they can act on an approved
  leave.
- **Cancelling to change the dates, then forgetting to re-apply.** The time off is not booked until a new
  request is approved.

## Troubleshooting

If there is no cancel option, the request is no longer pending.
