# Your notification inbox

> **Not available yet.** This feature is built and tested but is not in the version you are using today.

## What this feature does

Keeps every notification SkyTrack has sent you in one list, so nothing is lost if you miss it on your phone.

## Who can use it

Employees, for their own notifications.

## Step-by-step instructions

1. Open SkyTrack.
2. Select the **bell** at the top. A number on it shows how many are unread.
3. Select a notification to open the screen it refers to.

## Expected outcome

A list newest first, with unread ones marked. Opening one takes you to the relevant screen — a leave
decision opens your leave requests.

## Common mistakes

- **Assuming an empty inbox means nothing happened.** SkyTrack notifies about exceptions, not routine
  success — there is no "you checked in" message.
- **Assuming turning off phone alerts empties the inbox.** It does not. The inbox keeps working; only the
  phone notifications stop.
