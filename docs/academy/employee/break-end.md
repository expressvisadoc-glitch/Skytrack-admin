# How to end a break and resume work

## What this feature does

Ends the running break, adds its length to your break total for the day, and starts your working timer again.

## Who can use it

Employees with a break currently running.

## Prerequisites

A break is running. You do not need to be at the office.

## Step-by-step instructions

1. Open SkyTrack. The screen shows you are on a break.
2. Select the same button, now offering to **resume work**.

## Expected outcome

The break timer stops, its length is added to your day's break total, and your working timer starts again.

Each break's length is added to the total — a 20-minute break adds 20 minutes.

## Common mistakes

- **Forgetting to resume and then trying to check out.** You cannot check out while a break is running, so
  you have to resume first anyway.
- **Resuming twice.** The second attempt is refused — there is no break running.

## Troubleshooting

| Message | Meaning |
| :--- | :--- |
| "You are not currently on a break." | The break has already ended. |
| "You have not checked in today." | There is no day to resume. |
| "You have already checked out." | The day is closed. |
