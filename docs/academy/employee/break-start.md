# How to start a break

## What this feature does

Pauses your working day. While a break runs, your working hours stop adding up.

## Who can use it

Employees who have checked in and not yet checked out.

## Prerequisites

- You have checked in today.
- No break is already running.
- You have **not** checked out.

**You do not need to be at the office to start a break.** Breaks are not location-checked.

## Step-by-step instructions

1. Open SkyTrack. You should be in the **Working** state.
2. Select **Break**.

## Expected outcome

The screen shows you are on a break and a break timer starts. Your working-hours timer stops.

## Common mistakes

- **Taking a break to "pause" before checking out.** Check out instead — you cannot check out during a break.
- **Expecting each break to be listed separately.** SkyTrack records your **total** break time for the day,
  not a list of individual breaks.

## Troubleshooting

| Message | Meaning |
| :--- | :--- |
| "You have not checked in today." | Check in first. |
| "You are already on a break." | A break is running — resume work first. |
| "You have already checked out." | The day is closed. |
